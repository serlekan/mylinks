Save & publish

Drafts are stored only in this browser. Downloads let you commit changes manually. Publishing creates a commit in the configured GitHub repository; the deployment workflow then updates your site when configured.

Token stays in memory only; it is sent directly to api.github.com. It is never saved, exported, or committed. For shared/public computers, use JSON export instead. Open this page from a trusted deployment.

Public viewers can open the editor, but cannot publish without authorized repository credentials. Read the README for setup and Cloudflare deployment.
